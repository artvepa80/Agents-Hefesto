## Workflow

`action-smoke.yml` suma el caso C (SARIF sin subida): la Action escribe
`smoke.sarif`, la salida `sarif_file` es `smoke.sarif` y el log tiene
versión 2.1.0 y al menos un resultado `error`. Se empujó con el token con
permiso `workflow`.

## Procedimiento después del merge

1. Confirmar CI verde en `main`.
2. `git tag -a v4.15.0 -m 'v4.15.0' <sha del squash>` y empujar el tag.
3. `release.yml` verifica el tag, construye, hace `twine check`, sube a
   PyPI (`continue-on-error`) y crea la GitHub Release.
4. Verificar `https://pypi.org/pypi/hefesto-ai/4.15.0/json` (wheel y sdist).
5. Demo de Hugging Face y landing privada: ver el handoff del día.
