## Release procedure (after this PR merges)

1. Confirm CI on `main` is green.
2. `git tag -a v4.14.1 -m 'v4.14.1' <merge sha>` and push the tag.
3. `.github/workflows/release.yml` runs `verify_release_tag.py`, builds,
   `twine check`s, uploads to PyPI (`continue-on-error`) and creates the
   GitHub Release. Do not create the Release by hand.
4. Because the upload step can fail silently, verify
   `https://pypi.org/pypi/hefesto-ai/4.14.1/json` lists a wheel and an sdist.
5. Bump the Hugging Face demo Space (`HefestoAI/hefesto-demo`) to
   `hefesto-ai==4.14.1`; demo telemetry stays off (`HEFESTO_TELEMETRY=0`).
